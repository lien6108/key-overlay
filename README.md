# Key Overlay 使用說明書

[![下載 KeyOverlay.exe](https://img.shields.io/badge/%E4%B8%8B%E8%BC%89-KeyOverlay.exe-brightgreen?style=for-the-badge&logo=windows)](https://github.com/lien6108/key-overlay/releases/latest/download/KeyOverlay.exe)
[![最新版本](https://img.shields.io/github/v/release/lien6108/key-overlay?style=for-the-badge&label=%E7%89%88%E6%9C%AC)](https://github.com/lien6108/key-overlay/releases/latest)

Key Overlay 是一個 Windows 小工具，會在螢幕角落即時顯示你正在按的按鍵。同時按住的鍵會用 `+` 連起來，例如 `Ctrl + Shift + Z`。也可以再打開一個小鍵盤，你按哪個鍵，小鍵盤上對應的鍵就亮起來。

錄教學影片、做簡報示範、遠端帶人操作軟體時，觀眾不用猜你按了什麼。

```
┌──────────────────────────────┐
│ [Ctrl] + [Shift] + [Z]       │   ← 預設在主螢幕左下角、工作列上方
└──────────────────────────────┘
┌──────────────────────────────┐
│ Esc F1 F2 F3 …               │   ← 小鍵盤（選用），按下的鍵會亮
│ Tab Q  W  E  …               │
└──────────────────────────────┘
```

## 1. 三步驟開始使用

1. 點最上方的「下載 KeyOverlay.exe」按鈕（不需要安裝，也不需要 Python）
2. 雙擊開啟，在設定視窗挑一個顏色，按「開始執行」
3. 隨便按幾個鍵，左下角就會出現你按的按鍵

要關閉時按 **`Ctrl + Alt + Shift + Q`** 即可。

## 2. 下載

**點這個連結就會直接開始下載最新版**：

> **https://github.com/lien6108/key-overlay/releases/latest/download/KeyOverlay.exe**

或是點本頁最上方的綠色「下載 KeyOverlay.exe」按鈕，兩者是同一個檔案。

想看歷史版本或更新說明，到 [Releases 頁面](../../releases)，每個版本底下的「Assets」都附有 `KeyOverlay.exe`。

**不用下載整個專案的 ZIP**，那裡面只有原始碼，沒有 exe。

下載後把檔案放在任何你方便的位置都可以，例如桌面或 `D:\Tools\`。它是單一檔案，不會在旁邊產生其他東西。

## 3. 第一次執行

雙擊 `KeyOverlay.exe`。

**如果跳出藍色的「Windows 已保護您的電腦」視窗**：這是因為程式沒有購買數位簽章，Windows 對所有未簽章的程式都會這樣提示。處理方式：

1. 點視窗內的「**其他資訊**」
2. 點出現的「**仍要執行**」

之後再開啟就不會再問。

**如果防毒軟體攔下來**：請看[常見問題](#9-常見問題)裡「防毒軟體說它是惡意程式」一條。

## 4. 設定視窗怎麼選

每次開啟程式都會先出現一個小視窗，由上到下有這幾個部分：

**顯示顏色**
三種配色，右邊有實際效果預覽，點預覽圖也能選：

| 顏色 | 適合的情境 |
| :-- | :-- |
| 亮黃（預設） | 大多數深色或淺色畫面都看得清楚 |
| 亮藍 | 畫面本身有很多黃色或暖色時 |
| 亮白 | 深色背景的畫面、想要低調一點時 |

**顯示位置**
左下、右下、左上、右上四選一，按鍵面板和小鍵盤都會放在這個角落。程式跑起來之後也能從右下角圖示選單隨時切換。

**同時顯示小鍵盤**（核取方塊）
勾選後會多出一個小鍵盤，你按下哪個鍵，小鍵盤上對應的鍵就會亮起來；按鍵面板會疊在小鍵盤旁邊。適合要讓觀眾看清楚「按的是哪個位置的鍵」的教學。

**只顯示快捷鍵**（核取方塊）
勾選後，只有按住 `Ctrl`、`Alt` 或 `Win` 的時候才會顯示；一般打字、輸入密碼都不會出現在畫面上，小鍵盤也不會亮。**要錄影或直播時建議勾選**，避免不小心把帳號密碼秀出來。

**如何關閉**
列出兩種關閉方式，詳見[第 6 節](#6-右下角圖示選單小鍵盤換位置關閉)。

選好後按「**開始執行**」（或按 Enter）。按「取消」（或 Esc）則什麼都不會啟動。

你的每一項選擇都會自動記住，下次開啟時預設就是上次的設定。

## 5. 使用中會看到什麼

- **按鍵面板顯示在你選的角落**（預設主螢幕左下角、工作列上方），蓋在所有視窗之上，但不會搶走你的游標或鍵盤焦點，滑鼠點下去也會穿透到下面的視窗。
- **只顯示當下這一組**。放開所有鍵之後，畫面會停留 1.5 秒再淡出。
- **有開小鍵盤的話**，小鍵盤會一直待在角落，按鍵面板疊在它旁邊（下方角落時在上面、上方角落時在下面）。按住的鍵會以你選的顏色亮起，放開就恢復；左右兩邊的 Shift、Ctrl、Alt 會分別亮。
- **修飾鍵順序固定**為 `Win → Ctrl → Alt → Shift`，左右兩邊的 Ctrl、Shift、Alt 會合併顯示成一個。
- **螢幕右下角通知區域會出現一個黃色「K」圖示**，代表程式正在執行。Windows 11 預設可能把它收進隱藏區，點工作列右側的 `^` 就能看到。
- 程式不會出現在工作列，也不會出現在 `Alt + Tab` 切換清單裡。

## 6. 右下角圖示選單：小鍵盤、換位置、關閉

在螢幕右下角通知區域的黃色 **K** 圖示上按右鍵（或左鍵），會出現這個選單：

| 項目 | 作用 |
| :-- | :-- |
| **顯示小鍵盤** | 勾選就打開小鍵盤，再點一次就關掉 |
| **顯示位置 ▸** | 展開後有左上、右上、左下、右下，點一下立刻搬過去 |
| **結束 Key Overlay** | 關閉程式 |

這裡做的選擇同樣會記住，下次開啟沿用。

**關閉程式**，任選一種：

| 方式 | 操作 |
| :-- | :-- |
| **快捷鍵** | 在任何畫面按 **`Ctrl + Alt + Shift + Q`** |
| **通知區域圖示** | 在右下角黃色 **K** 圖示上按右鍵 →「結束 Key Overlay」 |

如果你忘了程式還開著、又再雙擊一次 `KeyOverlay.exe`，不會跑出第二個，只會跳出提示告訴你怎麼關閉。

## 7. 開機自動啟動

想讓它每次開機就自動在背景待命，而且不要每次都跳設定視窗：

1. 先正常開啟一次 Key Overlay，選好你要的顏色與選項，按「開始執行」（這一步是為了把選擇記下來）
2. 在 `KeyOverlay.exe` 上按右鍵 →「建立捷徑」
3. 在剛建立的捷徑上按右鍵 →「內容」→「目標」欄位最後面空一格，加上 `--no-dialog`，例如：
   ```
   "D:\Tools\KeyOverlay.exe" --no-dialog
   ```
   按「確定」
4. 按 `Win + R`，輸入 `shell:startup`，按 Enter，會打開「啟動」資料夾
5. 把剛才的捷徑拖進這個資料夾

之後開機就會直接用上次的設定啟動，不再跳視窗。要取消自動啟動，把捷徑從「啟動」資料夾刪掉即可。

## 8. 進階：用參數微調外觀

不需要改任何檔案，只要在捷徑的「目標」欄位後面加參數就能調整。多個參數用空格隔開，例如：

```
"D:\Tools\KeyOverlay.exe" --combos-only --font-size 16 --no-dialog
```

| 參數 | 預設值 | 作用 |
| :-- | :-- | :-- |
| `--font-size 數字` | 20 | 字級。想要更大更醒目就調高，例如 `--font-size 28` |
| `--hold 秒數` | 1.5 | 放開按鍵後停留幾秒才消失，例如 `--hold 3` |
| `--margin 像素` | 24 | 和螢幕邊緣的距離 |
| `--opacity 0.1~1.0` | 0.92 | 不透明度，數字越小越透明 |
| `--theme yellow`／`blue`／`white` | 上次的選擇 | 直接指定顏色，不走設定視窗的選擇 |
| `--position bottom-left`／`bottom-right`／`top-left`／`top-right` | 上次的選擇 | 顯示在哪個角落 |
| `--keyboard` | 上次的選擇 | 等同勾選「同時顯示小鍵盤」 |
| `--combos-only` | 上次的選擇 | 等同勾選「只顯示快捷鍵」 |
| `--no-dialog` | 關 | 不跳設定視窗，直接用上次的設定啟動 |
| `--version` | | 顯示版本號後結束 |

## 9. 常見問題

**右下角找不到黃色 K 圖示**
Windows 11 預設把不常用的圖示收起來。點工作列最右邊的 `^`（展開隱藏的圖示）就會看到。想讓它常駐顯示：「設定」→「個人化」→「工作列」→「其他系統匣圖示」，把 Key Overlay 打開。

**某些視窗裡按鍵抓不到**
工作管理員、部分安裝程式、以「系統管理員身分」開啟的程式，Windows 基於安全設計不允許一般程式讀取它們的按鍵。如果你需要在這些視窗示範快捷鍵，請在 `KeyOverlay.exe` 上按右鍵 →「以系統管理員身分執行」。鎖定畫面與 UAC 提示的按鍵則永遠抓不到，這是正常的。

**防毒軟體說它是惡意程式**
Key Overlay 要顯示按鍵，必須向 Windows 註冊「全域鍵盤監聽」，這和鍵盤側錄程式用的是同一個機制，加上 exe 沒有數位簽章，所以部分防毒或公司電腦的安控軟體會誤判。程式本身不會記錄、不會儲存、也不會上傳任何按鍵（詳見[第 10 節](#10-隱私與安全)）。若你信任它，可在防毒軟體把 `KeyOverlay.exe` 加入例外清單；若是公司電腦，請先詢問 IT 是否允許。

**雙螢幕時只在一個螢幕顯示**
目前只會顯示在「主螢幕」。要換到另一個螢幕，請到 Windows 顯示設定把那個螢幕設為主顯示器；要換角落則用右下角圖示選單的「顯示位置」。

**小鍵盤擋到我要示範的東西**
從右下角圖示選單的「顯示位置」換一個角落，或先取消「顯示小鍵盤」。小鍵盤和按鍵面板一樣是滑鼠穿透的，不會擋住你點擊底下的視窗。

**小鍵盤的按鍵和我的鍵盤排列不一樣**
小鍵盤固定是美式 65% 配置（沒有數字鍵盤區、F 鍵在最上排）。筆電或其他配置的鍵盤按下對應的鍵仍會亮，只是位置和實體鍵盤不完全相同。

**符號鍵顯示的名稱和我的鍵盤不一樣**
符號鍵名稱固定以美式鍵盤配置顯示，例如 `;` 或 `/`，其他語系鍵盤上對應位置的鍵會顯示成美式名稱。

**想重設回預設設定**
按 `Win + R`，輸入 `%APPDATA%\KeyOverlay`，按 Enter，刪掉裡面的 `settings.json` 即可。下次開啟就會回到預設：亮黃色、左下角、不顯示小鍵盤、不勾選「只顯示快捷鍵」。

**跳出「無法安裝鍵盤 hook」錯誤**
通常是安控軟體封鎖了鍵盤監聽。請參考上面防毒那一條，或改用系統管理員身分執行試試。

## 10. 隱私與安全

- **不連網**：程式沒有任何網路功能，不會回傳使用資料。
- **不記錄按鍵**：按鍵只用來畫出畫面上的那一組，畫完就丟掉，不寫入任何檔案。
- **只存一個設定檔**：`%APPDATA%\KeyOverlay\settings.json`，裡面只有你選的顏色、位置、是否顯示小鍵盤、是否只顯示快捷鍵。
- **錄影或直播請勾選「只顯示快捷鍵」**，這樣輸入密碼時按鍵面板不會出現、小鍵盤也不會亮。
- 程式碼公開在這個專案裡，任何人都能檢視。

## 11. 系統需求與已知限制

**系統需求**
- Windows 10 或 Windows 11
- 不需要安裝任何東西，不需要 Python

**資源用量**
- 閒置時 CPU 約 0%（沒按鍵時完全休眠）
- 記憶體約 20 MB

**已知限制**
- 以系統管理員身分執行的視窗裡的按鍵抓不到（除非 Key Overlay 也用系統管理員身分執行）
- 鎖定畫面、UAC 提示等安全桌面上的按鍵抓不到
- 只顯示在主螢幕
- 符號鍵以美式鍵盤名稱顯示，小鍵盤固定為美式 65% 配置
- 未簽章，第一次執行會遇到 SmartScreen 提示

## 12. 想自己修改程式？

Key Overlay 用純 Python 標準函式庫寫成，沒有第三方依賴。原始碼在 `key_overlay/` 資料夾。

```powershell
python -m key_overlay                      # 從原始碼直接執行
python -m unittest discover -s tests -v    # 跑測試
./build.ps1                                # 重新打包，產出 dist/KeyOverlay.exe
```

發佈新版本：改 `key_overlay/__init__.py` 裡的版本號，推送 `v*` 格式的 tag，GitHub Actions 會自動測試、打包並建立 Release，上方的下載連結就會指到新版。
